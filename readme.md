# Pemrograman Berorientasi Objek
## Praktikum Pertemuan ke-10

### Form Identitas Mahasiswa dengan Tkinter

Program ini merupakan tugas praktikum Pertemuan ke-10 pada mata kuliah Pemrograman Berorientasi Objek. Program dibuat menggunakan Python dan Tkinter untuk membuat form identitas mahasiswa.

### Fitur Program
- Mengisi nama dan NIM.
- Memilih program studi.
- Mengisi alamat.
- Tombol Simpan untuk menampilkan data.
- Tombol Reset untuk mengosongkan form.
- Tombol Keluar untuk menutup aplikasi.

### Materi yang Digunakan
Menggunakan widget Label, Entry, Button, Combobox, Text, dan geometry manager grid().

### Cara Menjalankan
python pratikum.py
